# STS2-Assistant
A simple AI assistant that analyses your game data to help make choices during the middle of a run. Using Ollama models and RAG based LLMs as the user interface.

-------------------------------------------------------------

Libraries Needed:

Python

Pydantic

Ollama

Mxbai-embed-large

ALIENTELLIGENCE/aidatascientistv2

-------------------------------------------------------------

Set Up:

Locate and copy the saves folder address for Slay the Spire 2

"C:/Users/xxxx/AppData/Roaming/SlayTheSpire2/steam/xxxxxxxxxxxxxxxxx/profile1/saves"

Paste the address in the SAVE_DIR variable in the save.py file

Run the main.py file to update the run history and in progress run JSON files

-------------------------------------------------------------

Running the program:

To ask the Assistant something, run the response.py file
